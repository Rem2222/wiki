# FreeToken — edge-MoE serving for personal hardware

## Что это

**FreeToken** — edge-native MoE serving-движок: запуск больших Mixture-of-Experts моделей
на персональном/потребительском железе (ноутбук → рабочая станция), трактуя весь ПК как
единый elastiчес-пул (CPU+GPU+RAM+PCIe), а не маленький GPU.

- Репо: github.com/FlashML-org/FreeToken
- Статья: arxiv.org/abs/2608.16157 (авг 2026, UC Berkeley / MIT / UT Austin)
- Дистрибутивы: Windows + Linux, flashml.ai (GUI, не GGUF, без сборки из исходников)
- Поддержка 20+ MoE-моделей, встроенные агентные обвязки

## Ключевая идея

MoE активирует лишь малую часть экспертов на токен → не нужно держать сотни ГБ в VRAM.
FreeToken сам решает: что оставить в VRAM, что временно догружать из RAM на GPU,
что считать на CPU. Bandwidth-adaptive execution (адаптация к скорости CPU/GPU/PCIe).

- Prefill: prefetch экспертов следующего слоя
- Генерация: динамическое распределение вычислений по текущей нагрузке
- **Agent State Cache** — при вызове инструментов / продолжении задачи пропускает
  большую часть повторной обработки контекста (релевантно агентам)

## Заявленные результаты (из статьи)

| Модель | Железо | Скорость |
|---|---|---|
| Qwen3.6 35B | ноутбук, RTX 4060 8GB | 39 ток/с |
| DeepSeek-V4-Flash 284B | RTX 5090 | 22–25 ток/с |
| GLM-5.2 753B | RTX PRO 6000 | 15 ток/с |

Сравнение с Ollama: генерация выше в 3–4×, обработка входного контекста в 6–30× быстрее.
Быстрее медианной скорости Codex (33 ток/с).

## Состояние для машины Романа (XE2690: GT 1030 2GB CPU-only, 64GB RAM)

⚠️ **Честная оценка — не сулить:**

- Приведённые цифры начинаются с **8GB VRAM** (RTX 4060). GT 1030 2GB далеко ниже этого спектра.
- ✅ 64GB RAM дают шанс запустить 35B-MoE через CPU+RAM + подливание в маленький VRAM,
  но это будет **сильно медленнее** заявленных 39 ток/с (единицы-десятки на малых контекстах;
  prefill через CPU медленный).
- ⚠️ GT 1030 — Pascal, старые драйверы; проверить совместимость билда, возможен CPU-only режим.
- Не ждать интерактивных ток/с; но для агенто-задач (не чата) может быть применимо.
