# FreeToken — edge-MoE serving for personal hardware

## Что это

**FreeToken** — edge-native MoE serving-движок: запуск больших Mixture-of-Experts моделей
на персональном/потребительском железе (ноутбук → рабочая станция), трактуя весь ПК как
единый elastiчес-пул (CPU+GPU+RAM+PCIe), а не маленький GPU.

- Репо: github.com/FlashML-org/FreeToken
- Статья: arxiv.org/abs/2608.16157 (авг 2026, UC Berkeley / MIT / UT Austin)
- Дистрибутивы: Windows + Linux, flashml.ai (GUI, не GGUF, без сборки из исходников)
- Поддержка 20+ MoE-моделей, встроенные агентные обвязки

## Ключевая идея

MoE активирует лишь малую часть экспертов на токен → не нужно держать сотни ГБ в VRAM.
FreeToken сам решает: что оставить в VRAM, что временно догружать из RAM на GPU,
что считать на CPU. Bandwidth-adaptive execution (адаптация к скорости CPU/GPU/PCIe).

- Prefill: prefetch экспертов следующего слоя
- Генерация: динамическое распределение вычислений по текущей нагрузке
- **Agent State Cache** — при вызове инструментов / продолжении задачи пропускает
  большую часть повторной обработки контекста (релевантно агентам)

## Поддерживаемые модели и ресурсы

### Dense-модели (все параметры активны)

| Модель | VRAM (BF16) | VRAM (FP8) | VRAM (NVFP4) |
|--------|-------------|------------|--------------|
| Qwen3.6-27B | ~54GB | ~27GB | ~13.5GB |

### MoE-модели (активна малая часть экспертов)

| Модель | Всего параметров | Активных на токен | VRAM (BF16) | VRAM (FP8) | VRAM (NVFP4) |
|--------|-----------------|-------------------|-------------|------------|--------------|
| Qwen3.6-35B-A3B | 35B | **3B** | ~70GB | ~35GB | ~17GB |
| Qwen3-30B-A3B | 30B | **3B** | ~60GB | ~30GB | ~15GB |
| Gemma-4-26B-A4B | 26B | **4B** | ~52GB | ~26GB | ~13GB |

**Ключевой момент:** MoE-модели активируют только 3B параметров на токен, поэтому
для инференса нужно гораздо меньше VRAM, чем кажется. FreeToken держит в VRAM кэш
экспертов + KV-память, а остальное грузит из RAM.

## Требования к системе

- **OS:** Linux x86_64 или Windows
- **GPU:** NVIDIA RTX 30/40/50 серии (требуется CUDA 13, драйвер r580+)
- **RAM:** 32GB+ (для MoE-моделей, эксперты живут в RAM)
- **Диск:** 20–70GB на модель (зависит от квантизации)
- **⚠️ GT 1030 / старые GPU:** не совместимы (Pascal, нет CUDA 13)

## Установка и запуск

```bash
# Установка
uv pip install "freetoken[accel]"

# Запуск сервера
ft serve --model ~/models/Qwen3.6-35B-A3B

# Проверка
curl http://127.0.0.1:1919/v1/models

# Запуск агента
ft launch hermes  # или claude / codex / opencode
```

## MoE backends

`ft serve --moe-backend {auto,fused,offload,cpu,hybrid}`:

- **fused** — эксперты в VRAM (нужен большой VRAM)
- **offload** — эксперты в RAM, LRU-кэш на GPU, промахи грузятся через PCIe
- **cpu** — промахи считаются на CPU
- **hybrid** — комбинация: часть через PCIe, часть на CPU, с перекрытием
- **auto** — dense → fused; MoE → offload (или hybrid при профиле)

## Состояние для машины Романа (XE2690: GT 1030 2GB, 64GB RAM)

⚠️ **Честная оценка:**

- GT 1030 2GB — **не совместим** с FreeToken (нет CUDA 13, Pascal)
- 64GB RAM — достаточно для MoE-моделей, но без GPU инференса не будет
- **Рекомендация:** купить RTX 3060 12GB (б/у, 15–20K руб.) — лучшее соотношение цена/VRAM
- После покупки GPU: FreeToken + Qwen3.6-35B-A3B → ~30–35 ток/с, интерактивный чат
