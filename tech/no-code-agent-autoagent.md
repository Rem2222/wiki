# no-code-agent-autoagent

**Репозиторий:** https://github.com/HKUDS/AutoAgent
**Лицензия:** MIT
**Звёзды:** ~3k+ ⭐ (быстро растёт)

## Суть

Zero-code фреймворк для создания LLM-агентов из природного языка. Описываешь высокоуровневую цель — система сама делает планирование, декомпозицию задач и исполнение.

## Ключевые фичи

| Фича | Описание |
|------|----------|
| Natural Language-Driven | Автоматическое построение и оркестрация агентов через диалог |
| Zero-Code | Не требует навыков программирования |
| Self-Managing Workflow | Динамическое создание и оптимизация воркфлоу на лету |

## Контекст

Академическая работа (HKUDS — University of Hong Kong). GAIA benchmark — показывает сильные результаты. Research-ориентированный, production-трека нет.

## Статус

🔎 На рассмотрении. Интересен как концепция — генерация агентов из NL, — но для production не подходит. У нас Hermes + конфиги дают больше контроля.
