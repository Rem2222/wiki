# Yandex Station Extended — открытая вики о доступе к колонкам Яндекса

## Что это

**Yandex Station Extended** (`hackalice.me`) — открытая community-вики о доступе к умным колонкам Яндекса и о том, что с ними делать после доступа. Главная мысль: внутри Станции обычный Linux, и им можно пользоваться как своим — поставить SSH, свой софт, USB-периферию, AirPlay, свою LLM вместо Алисы.

Объём на 05.11.2026: **73 страницы**, **17 разобранных моделей**, **17 рецептов**. Контент под CC-BY-4.0, сайт на MkDocs Material, хостинг GitHub Pages, деплой через GitHub Actions.

## Что внутри

Доступ и закрепление:

- root без разборки — у каждой модели свой способ: DNS-метод, правка CA из factory mode, ADB по USB, приложение для Android, AliceBridge для Станции 1-го поколения
- SSH и отключение обновлений, чтобы доступ не пропал
- пакеты: `yse` (Entware и `.yap`), YAM с веб-панелью и Lua-плагинами

Периферия и звук:

- USB Host (флешки, USB-Ethernet, наушники, ЦАП), подсветка, обработанный микрофон VQE
- AirPlay, Spotify Connect, любой плеер как Bluetooth-источник, YouTube Music, свои звуки, озвучка своего текста
- ТВ-набор для Станции 1: веб-пульт, ТВ-лаунчер, YouTube и VPN на HDMI

Свои модели вместо Алисы:

- Home Assistant как голосовой спутник
- своя LLM на колонке или через ПК, ChatGPT Voice
- «колонка без Яндекса» — полностью автономный режим

Внутренности:

- прошивка quasar, сеть и порты, голосовой тракт Алисы, директивы и вызовы, zigbee, телеметрия, сборка своего состава

## Модели и состояние root

- Постоянный root: Лайт, Лайт 2, Мини, Мини 2, Мини 3, Миди, Станция 1, Станция 2, Станция 3, Стрит, Умный хаб, JBL Link Music, Fiero Hi
- Только закрепление доступа: Мини 3 Про
- Разовые команды с повышенными правами, постоянного root нет: Станция Макс (`YNDX-0008`) — мешает dm-verity; отдельная страница у варианта с Zigbee

## Что учесть

- Две недели истории — мало. Ошибки в рецептах возможны, проверять по своей модели, а не по общей таблице
- Root на колонке: снятие с гарантии, риск получить нерабочее устройство, и EULA Яндекса это запрещает. В README есть оговорка «для своих устройств», но юридически она ничего не меняет
- Часть способов завязана на конкретные версии прошивки: Яндекс их закрывает, и рецепт устаревает молча

## Чем интересно Роману

- Раздел **«Как это устроено»** — прошивка quasar, сетевые порты, голосовой тракт — годный материал про устройство умной колонки даже без колонки под рукой
- Рецепт **«своя LLM вместо Алисы»** перекликается с домашним стеком: Home Assistant + свой бэкенд + локальная модель
