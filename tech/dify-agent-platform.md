# dify-agent-platform

**Репозиторий:** https://github.com/langgenius/dify
**Сайт:** https://dify.ai
**Лицензия:** Apache-2.0 **с дополнительными условиями** (ограничения на мультитенантный хостинг и удаление брендинга — не «open source без оговорок»)
**Звёзды:** 158 910 ⭐ (19.10.2026), последний релиз 1.17.1 (10.09.2026)

## Суть

Production-ready open-source платформа для разработки LLM-приложений. Промпт-инжиниринг, RAG-пайплайны, агенты, мониторинг в рантайме.

## Ключевые фичи

| Фича | Описание |
|------|----------|
| Prompt Engineering | Визуальное управление промптами |
| RAG Pipelines | Загрузка документов, эмбеддинги, поиск |
| Agent Logic | Инструменты, цепочки, мульти-агенты |
| Observability | Мониторинг в рантайме, трейсинг |
| Multi-User | Командная работа |

## Системные требования

- CPU >= 2 Core
- Self-hosted или облако

## Статус

✅ Стандарт индустрии. Не замена Hermes (это платформа AI-приложений, не автономный агент), но может быть полезен для UI-воркфлоу и промпт-инжиниринга.
