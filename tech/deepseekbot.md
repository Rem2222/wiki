# DeepSeekBot (DSB)

## Что это

MIT-плагин для [DeepSeek Harness](tech/deepseek-harness) от независимой команды BotHarness: превращает DSH в команду персональных ботов (GrokBot-подход). У каждого бота — имя, характер, пиксель-аватар и **память = обычный Git-репозиторий** (можно смотреть diff, откатывать, пушить на GitHub и переносить между машинами).

- **Репозиторий:** https://github.com/BotHarness/DeepSeekBot
- **Сайт:** https://deepseekbot.app (доки, changelog, Bot Market, аватар-фабрика)
- **npm:** `deepseekbot@1.3.1` (2026-10-14), требует DSH ≥ 0.2.0-rc.2
- **Stars:** 127 (18.10.2026), forks 9, MIT, TypeScript, Node ≥ 22
- **Установка:** DSH → Плагины → Добавить → `deepseekbot@1.3.1` → «Bot Mode» в сайдбаре

## Возможности

- **Команда ботов** — исследователь/писатель/инженер, каждый со своей личностью и памятью
- **Git-память** — каждый бот = git-вуд: коммиты, diff, откат к любой версии, шеринг через GitHub
- **Группы** — @-упоминания, делегирование задач с отчётами, «твоё решение нужно» — сигнал человеку
- **IM-выход** — бот отвечает своим лицом в Slack, Discord, Feishu/Lark, QQ, WeChat (в WeChat умеет файлы и голос→текст)
- **Расписания** — «каждый день в 9 утра шли дайджест» — бот сам создаёт таймер
- **Computer use** — по одобрению: браузер/клики/скриншоты, живой просмотр и пауза
- **MCP и секреты** — по одобрению пользователя; MCP конфигурируется одной фразой
- **Bot Market** — готовые боты для установки/шаринга (zip-экспорт)
- **Модели** — любые провайдеры, настроенные в DSH (не только DeepSeek)

## Версии (свежее)

- **1.3.1** (14.10.2026) — установка из плагинов в один шаг без approve-построения; CLI: Host, browser/computer, IM-приложения
- **1.3.0** (14.10.2026) — единая дизайн-система; Orchestrator сам разбирает инбокс; MCP + секреты по одобрению; экспорт переписок; откат памяти к любой версии
- **1.2.x** (12.10.2026) — фиксы установки, группа-аватары, аудио/файлы в чате
- **1.2.0** (08.10.2026) — пиксельные окна-компаньоны на десктоп; кросс-IM (один бот = все мессенджеры); импорт/экспорт ботов zip
- **1.1.0** (06.10.2026) — таймеры; личность+ядро памяти в каждом контексте; one-click update; WeChat голос→текст
- **1.0.1** (05.10.2026) — первый стабильный: PersonaBots, Git-память, группы, делегирование, аватары, IM, первый Market

## DSB vs DS Bot (не путать!)

| | DeepSeekBot (DSB) | DS Bot (Fei2411/DeepSeek-Bot, npm `ds-bot`) |
|---|---|---|
| Уклоны | боты-коллеги вне окна DSH, Git-память, IM-личности | DSH как чат-приложение, главный «Chief»-бот, контроль токенов |
| Память | Git-вуд на бота, пушится и шарится | Markdown, авто-ревью после каждого раунда, личная/командная |
| IM | Slack, Discord, Feishu/Lark, QQ, WeChat | GitHub connector |
| Лицензия | MIT | Apache-2.0 |

Оба — не официальные продукты DeepSeek.
