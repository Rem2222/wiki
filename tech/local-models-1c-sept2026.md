# Локальные модели для 1С — подборка (сентябрь 2026)

## 1. Qwen 3.8 27B — fine-tuned под 1С

**Модель:** [sweetand/qwen3.8-27b-1C](https://huggingface.co/sweetand/qwen3.8-27b-1C)

Кто-то дообучил Qwen 3.8 27B на данных 1С. Утверждение «забудьте про кодинг на локальных моделях» можно считать устаревшим.

- Базовая модель: Qwen 3.8 27B
- Дообучение: на 1С-данных (код, конфигурации)
- Назначение: генерация/понимание кода 1С
- Статус: **нужно тестить**

### Где тестировать
- **CPU-only станция (XE2690, 64GB RAM):** 27B модель влезет, но будет медленно (~8-15 t/s с Bonsai-квантованием)
- **Mac (ARM):** теоретически более приличная скорость за счёт производительности на/token
- **GPU:** если есть RTX 3060+ (12GB VRAM) — можно запустить Q4 квантование

## 2. USER2-1C-code — embedding модель для 1С

**Модель:** [PruhaNLP/USER2-1C-code](https://huggingface.co/PruhaNLP/USER2-1C-code)

Маленькая и быстрая embedding модель, дообученная на домене 1С.

- Назначение: семантический поиск по коду 1С
- Размер: маленький (быстрый инференс)
- Дообучение: на 1С-данных (XML, конфигурации, модули)

### Зачем это нужно
- **Вместо routerai/openrouter для индексации 1С** — можно индексировать локально
- Модель «не особо умная», но дообучение на специализированном домене даёт результат сопоставимый с «тяжёлым» Qwen 8B
- Потенциал: если научить понимать XML-ы 1С с их семантикой — получится полноценный семантический поиск по конфигурациям

### Идея для развития
1С-объекты (справочники, документы, регистры) имеют свою семантику. Если embedding модель «понимает» что справочникНоменклатуры — это не просто XML, аビジネス-объект,то поиск по коду becomes qualitatively different.

## 3. Bonsai 2 — Qwen 3.8 в 6GB

**Ссылка:** [prismml.com/news/bonsai-2-27b](https://prismml.com/news/bonsai-2-27b)

Та же Qwen 3.8 27B, но уложенная в ~6GB через трёхзначное квантование. 98% от оригинала.

- Размер: ~6GB (вместо ~55GB полной версии)
- Качество: ~98% от Qwen 3.8 27B
- Поддержка: vision + tool calling
- Лицензия: Apache 2.0

### Практическое применение
- XE2690 (64GB RAM): 6GB модель влезет с запасом, inference ~8-15 t/s
- Mac (ARM): ещё быстрее
- Подходит для: кодинг 1С, математика, общие задачи
