# Scenario 3D Collection — 1342 AI-модели с CC BY 4.0 (Hugging Face)

**Scenario 3D Collection** — открытый набор AI-сгенерированных 3D-моделей на Hugging Face. Проверено 24.10.2026 по API и README датасета.

- Датасет: https://huggingface.co/datasets/scenario-labs/3d-collection
- Автор: `scenario-labs` (Scenario) · лицензия **CC BY 4.0**, атрибуция «Scenario»
- Обновлён 19.10.2026 · 693 скачивания · 93 лайка · не gated, не приватный

**Статус: не скачано.** Записано по факту проверки; на диск ничего не качалось (см. раздел про размер).

## Что внутри

- **1 342 отобранных примера**, 1 500 выходных файлов, **~39 ГБ** суммарно (включая превью и исходные входные ассеты)
- 3 699 файлов в репозитории, по расширениям: **1 279 GLB**, 1 389 JPG (превью), 778 PNG, **144 Blender (.blend)**, **41 SPZ** (гауссовы сплаты), 25 PLY, 21 VOX, 8 FBX, 2 glTF, 2 OBJ
- Манифест: `data/train-00000-of-00001.parquet` — одна строка на пример, в ней структурированный промпт, effort, настройки генерации (JSON-строка `inputs.settings`), SHA-256 каждого файла и готовые ссылки на скачивание (`input_files`, `output_files`)

## Оговорки авторов (важно)

- Проверки **структурные**: все 137 Blender-сцен открылись с отключённым авто-исполнением. Качество рендера и анимации **не сертифицируется**.
- В одной Blender-сцене не хватает двух текстур.
- Модели **AI-сгенерированные** — это не фотосканы и не работа художника: геометрия гладкая, топология машинная. Для прототипов, фонов и заглушек годится, для продакшн-ассетов AAA-уровня нет.

## Второй датасет — Hunyuan (в постах про него не пишут)

- https://huggingface.co/datasets/scenario-labs/3d-collection-hunyuan
- **393 примера**, 1 144 файла, обновлён тоже 19.10.2026, 3 лайка
- Лицензия — **`other`**, то есть условия Tencent Hunyuan, **не CC BY**. Для коммерческого использования надо читать их лицензию отдельно; смешивать с первым датасетом в одном проекте не стоит, не разобравшись.

## Размер и как качать выборочно

Полный набор — 39 ГБ. На нашем VPS свободно 25 ГБ (диск занят на 75% после уборки 23–24.10), поэтому целиком не влезает и не нужно.

Достаётся точечно через манифест:

```python
import json
from datasets import load_dataset

ds = load_dataset("scenario-labs/3d-collection", split="train")
ex = ds[0]
print(ex["prompt"], ex["effort"])                    # по чему фильтровать
urls = ex["output_files"]                            # прямые ссылки на файлы
settings = json.loads(ex["inputs"]["settings"])      # параметры генерации
```

Либо скачать один GLB напрямую, без клиента datasets:

```
https://huggingface.co/datasets/scenario-labs/3d-collection/resolve/main/assets/<hash>/<file>.glb
```

Точные пути и хеши берутся из parquet-манифеста. 5–10 моделей — это десятки-сотни мегабайт.

## Куда применимо у нас

- **arcengine** — тестовые ассеты для 3D-кита, чтобы не моделировать заглушки руками.
- **ccgs** — визуал инвентаря и карточек (сундуки, оружие, стилизованные предметы).
- **3DGS-эксперименты** — 41 файл `.spz` (гауссовы сплаты) интересны отдельно, если дойдёт до splatting-пайплайна.

## Вывод

Хороший «расходник» для прототипирования: лицензия CC BY 4.0 позволяет свободно использовать с атрибуцией, форматы удобные (GLB для веба, .blend для правки), манифест даёт выборку без выкачивания всего массива. Для серьёзных проектов модели придётся доводить руками — это заявлено и самими авторами.
