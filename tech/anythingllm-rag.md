# anythingllm-rag

**Репозиторий:** https://github.com/Mintplex-Labs/anything-llm
**Лицензия:** MIT
**Звёзды:** ~25k+ ⭐

## Суть

Full-stack приложение для превращения документов (PDF, Word, код) в контекст для LLM. ChatGPT-like UI, self-hosted, multi-user.

## Ключевые фичи

| Фича | Описание |
|------|----------|
| RAG | Загрузка любых документов, векторный поиск |
| Multi-User | Командная работа, роли |
| Self-Hosted | Полный контроль над данными |
| Desktop | Mac, Windows, Linux версии |
| Агенты | Базовые агентные воркфлоу |

## Языки

English, 简体中文, 日本語

## Статус

🔎 Может быть полезен как RAG-бэкенд для документов, если GBrain не закрывает потребность. Не замена Hermes — это чат с документами, не автономный агент.
