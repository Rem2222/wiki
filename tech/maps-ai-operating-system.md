# MAPS — AI Operating System (прамп-гайд)

## Что это

Бесплатный промпт-гайд **pavrus117/ai-os-maps-guide** — компаньон к видео «Turn Claude Code Into Your AI Operating System (4 Layers)». Не софт: репо = один README + PDF. На каждую из четырёх слоёв — по готовой промпт-карточке, которая ведёт агента за руку.

- 🐙 https://github.com/pavrus117/ai-os-maps-guide
- 🎥 https://www.youtube.com/watch?v=Zs3faMCDYNs (видео; дашборд-лейауты V1+V2 — платный мембершип $15/мес, гайд бесплатен)
- 110 ⭐, 44 форка, создан 2026-09-22, лицензии на репо **нет**

## Четыре слоя (строить строго в этом порядке)

| | Слой | Одной строкой |
|---|---|---|
| **M** | Memory | одна карта всего, чем занимаешься — агент находит любой факт без указания файла |
| **A** | Agent | тот же агент на двух машинах: ноутбук + ящик, который не спит |
| **P** | Pulse | рутины, работающие когда ноутбук закрыт |
| **S** | Screen | дашборд, который **показывает** и никогда не хранит то, что показывает |

Автор честно про порядок: дашборд строится **последним** и даёт **~20% ценности**. Экономят карта и рутины.

### «Четыре лестницы» (самооценка уровня)

| Слой | Ур.1 | Ур.2 | Ур.3 |
|---|---|---|---|
| Memory | пачка папок, агент читает 20 файлов на один вопрос | signpost-файлы вместо папок | сгенерированная карта, проверяемая каждую ночь |
| Agent | агент на ноутбуке | + ящик, который не спит | одна папка живёт на обеих |
| Pulse | всё руками | задачи по расписанию на ноутбуке, ноутбук закрыт — всё встало | рутины без тебя |
| Screen | красивый граф, на который смотришь | панели читают реальные файлы | дашборд с кнопками, правильная машина делает работу |

## Карточки

### Card 0 — интервью перед построением

Не пиши карту сам. 20 минут вопросов по одному дают больше, чем полдчика перечисления папок. Каждая сессия оставляет файл `interviews/<дата>-<тема>.md`. Темы по порядку: чем бизнес и для кого, пять еженедельных дел, кому и чем должен прямо сейчас, где реально лежат файлы и заметки, что забываешь. Толкайся против расплывчатых ответов. На «stop» — первый черновик карты.

### Card 1 — Memory

Суть не в истории чатов, а в том, найдёт ли агент файл сам. Наверху — короткий файл (**у автора 40 строк**), где **нет ни одного факта**, только указание, где что живёт, по строке на область. Каждая строка ведёт на signpost-файл области, тот — на реальные документы. **Любой документ в двух шагах от верха.** Идея signpost — у Jay E (видео «Agentic OS»), сгенерированная карта и ночной чекер — авторские добавки.

Два правила:
- **У каждого факта ровно один дом.** Никуда не пишется дважды.
- **Ночью крутится маленький чекер**, который флагает signpost, указавший на сдвинувшийся файл — карта не может молча протухнуть.

**Замеренный эффект.** Один и тот же вопрос («какие слова мне запрещены в LinkedIn-посте и где это записано?») в двух свежих сессиях:

| | Без карты | С картой |
|---|---|---|
| Время | 1:02 | 0:30 |
| Токены (строка Messages в /context) | 27.7k | 16.8k (−40%) |

Второй прогон: разница в чтении почти сошла, но карта всё равно вдвое быстрее.

Сам промпт (перевод смысла): сгенерируй мастер-signpost до 60 строк со списком областей, на каждую область — signpost до 80 строк с фиксированными секциями **Projects, State, Skills, Memory, Routines, Not here**; каждая строка вида `- [name](absolute path): one-line note`; сначала только имена и пути, заметки оставь мне; один факт — один дом; потом напиши чекер, что каждый путь существует, у каждого signpost все шесть секций в правильном порядке, и флагает папки проекта, не попавшие ни в область, ни в архив; один выход, exit != 0 при любой проблеме.

### Card 2 — Agent

Одна и та же папка на ноутбуке и на арендуемом VPS, синк сам через **git каждые 5 минут в обе стороны**. Два условия:

- **Держи его вне публичного интернета.** Tailscale (бесплатно) — ноут, телефон и сервер в своей приватной сети, публичного адреса нет.
- **Сознательно ограничь того, кто там работает.** Один settings-файл запрещает всё, что умеет отправлять/шарить/удалять: письмо он может **написать**, а отправить — нет. Худшее, что он сделает — оставит черновик.

Про ToS: подписку Anthropic через чужой харнесс нельзя. Можно — сам Claude Code на сервере, официальный setup-token flow, своей учёткой, без доплат. Для других провайдеров правила свои.

Опционально — телефон: Telegram-бот на сервере, голос → текст → классификация (вопрос по файлам / добавить заметку / показать план дня) → ответ тем же ограниченным профилем, всё логируется в датированный файл.

### Card 3 — Pulse

Один файл-реестр рутин: имя, расписание, **какая машина** исполняет, промпт/скилл, модель, усилие, разрешённые инструменты, лимит ходов, таймаут, куда уходит вывод. Скедулер на каждой машине раз в 5 минут читает реестр и запускает то, что подошло по времени. Каждый прогон пишет строку лога: время, имя, модель, ходы, стоимость, статус. Из этого же лога читаются **две пробки**: дневной потолок и короткое rolling-окно — чтобы сбоющая рутина не сожгла месячную квоту за ночь.

Первая рутина — утренний дайджест: что было за ночь, что по плану, кто ждёт, — приходит в чат до того, как ты проснёшься.

### Card 4 — Screen

Правило, которое стоит держать даже без дашборда: **show, don't store**. Каждая панель читает файл, который уже написал кто-то другой. Ноут строит панели о своей неделе (там живёт трекер), сервер — доску рутин (там они крутятся), мозг пересобирается каждую ночь из заметок. Сама страница ничего не хранит — можно спокойно смотреть с телефона в отпуске, и если дашборд завтра умрёт, потеряешь ноль: каждый факт лежит в файле, который твой.

Дашборд: стандартная библиотека, без фреймворков и сборки; отдаёт один HTML + JSON под `data/`; **только читает** этот каталог; у каждой панели свой таймстемп и пометка stale вместо скрытия старого значения; bind на loopback или приватную сеть, никогда не на публичный порт; без cookies, логина и стороннего JS.

**Уровень 3 — кнопки.** Кнопка play рядом с рутиной **не запускает** ничего сама — она кладёт файл-запрос (имя, время, кто запросил) в очередь. Раннер подхватывает его на следующем проходе, но только на той машине, которую реестр назначил для этой рутины, под теми же пробками, и удаляет запрос после логирования. Дашборд по-прежнему ничего не пишет в свою папку данных.

### Card 5 — Brain (6 видов одного графа)

Строится **последним**. Один JSON, который ночной скрипт пишет, обходя карту из Card 1: каждый файл — узел, каждый signpost/ссылка — ребро. Страница рисует этот один файл шестью способами под тумблером.

Схема данных:
```
nodes: [{id, kind, label, area, layer, path, note, changed}]
  kind  ∈ {root, area, project, skill, memory, note, routine, run, app}
  layer ∈ {core, memory, skills, routines, apps, runs}
links: [{s, t}]
```

Виды: **rings** (концентрические по layer, root в центре), **circle** (все на одном кольце, связи поперёк), **areas** (кластер на область), **links** (force-layout), **timeline** (верх — прогоны рутин по дням, низ — файлы по последнему изменению), **3d orbit** (медленная 2.5D-проекция, крутится сама).

Реализация: d3 **вендored, не CDN**, тёмная тема; цвет по area, форма по kind, размер точки по числу связей; легенда с изоляцией одной area/kind; тумблеры names/motion, fit и fullscreen; hover гасит всё кроме узла и его связей; клик — карточка с label/note/path и кнопками open (текст файла, read-only маршрутом дашборда), copy path, fly-to (анимация камеры); поиск по label/path/note с fly-to; бюджет анимаций 60 fps на ноутбуке; **один константный блок вверху скрипта**, где живут все скорости и счётчики.

## Три вопроса до строительства

1. Может ли агент найти любой факт о твоей работе в **два хопа**, не указывая файл?
2. Работает ли что-то в твоей схеме, **когда ноутбук закрыт**?
3. Твой дашборд только показывает — или уже тихо стал местом, где живёт правда?

## Зачем это Rem

У Rem три слоя из четырёх уже есть, часто лучше:

| Слой MAPS | Что у Rem |
|---|---|
| Memory | `~/Documents/wiki/` + zvec (гибрид bge-m3 + FTS) + OpenViking + index.md. Signpost-идея частично в index.md → страницы, ночной чекер путей уже есть — `wiki-health-check.py` |
| Agent | Hermes на VPS + Hermes Desktop на Win. Git-синк между ними **не поставлен** |
| Pulse | Hermes cron (ночная рутина, адъютант, ночной дозор, обнова мультика...), капы частично через `/gquota` |
| Screen | Beszel + Grafana + Prometheus + skills dashboard. «Show, don't store» выполняется у Beszel/Grafana по построению |
