# langchain-open-agent-platform

**Репозиторий:** https://github.com/langchain-ai/open-agent-platform
**Автор:** LangChain
**Лицензия:** MIT

## Суть

Веб-интерфейс для создания и управления LangGraph-агентами. Вместо сокрытия логики — показывает поток выполнения: узлы, связи, циклы.

## Ключевые фичи

| Фича | Описание |
|------|----------|
| Visual Graph Builder | Drag-and-drop узлы и связи |
| LangGraph Native | Полная мощь LangGraph без кода |
| Agent Supervisor | Оркестрация нескольких агентов |
| LangSmith | Интеграция трейсинга |
| Tools + RAG | Подключение инструментов и RAG-серверов |

## Статус

🔎 Самое честное из no-code решений — не скрывает граф, а делает его наглядным. Но завязано на LangChain/LangGraph. Полезно, если в будущем понадобятся сложные графы агентов за пределами linear loop Hermes.
