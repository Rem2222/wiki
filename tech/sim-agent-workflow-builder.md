# sim-agent-workflow-builder

**Репозиторий:** https://github.com/simstudioai/sim
**Автор:** SimStudio AI

## Суть

Визуальный конструктор агентных воркфлоу со встроенным AI Copilot. Проектируешь пайплайны в виде графов — AI может их генерировать и изменять за тебя.

## Ключевые фичи

| Фича | Описание |
|------|----------|
| Visual Builder | Графовый редактор воркфлоу |
| AI Copilot | Генерация и модификация графов через ИИ |
| Execution Tracing | Подробный трейсинг каждого шага агента |
| Executable Graphs | Не диаграммы — работающий код |

## Статус

🔎 Самый недооценённый из пятёрки. Похож на OAP (LangChain), но с AI-генерацией вместо ручной сборки. Трейсинг выполнения — сильное преимущество для дебага сложных цепочек.
