| **Материнка** | **Huananzhi X99-TF** | C612 чипсет, 10-слойный PCB, **6-фазное питание (VRM)**, DDR3+DDR4, 2xM.2 NVMe, куплена на Ali 22.09.2022 |

## Узкие места (по приоритету)

### 🔴 1. Место на дисках

**2.37 / 2.50 ТБ занято.** 130 ГБ свободно — новые модели туда уже не влезут.

**Решение:** очистить существующий NVMe на 500 ГБ — не нужно покупать новый.

### 🟡 2. GPU для LLM

**GT 1030 (2 ГБ)** — самые маленькие модели (3B) не влезают целиком в VRAM. Для CPU инференса через llama.cpp GPU не участвует.

**Варианты апгрейда:**

| Карта | VRAM | Бюджет (б/у) | Что запустит |
|-------|------|-------------|-------------|
| **RTX 3060** | 12 ГБ | ~15-18к ₽ | Gemma 12B Q4 целиком, Qwen 32B Q4 — не влезет |
| **Tesla P40** | 24 ГБ | ~20-25к ₽ | Qwen 32B Q4, Llama 70B Q3, нужен активный обдув |
| **RTX 3090** | 24 ГБ | ~50-65к ₽ | Всё, включая игры |

**Фишка Tesla P40:** максимальная VRAM за рубль. Но: пассивное охлаждение (нужен вентилятор), нет видео-выходов, только compute.

### 🟢 3. CPU — апгрейд в тот же сокет ✅ ПОДТВЕРЖДЕНО

**Материнка: Huananzhi X99-TF** (C612 чипсет, куплена на AliExpress 22.09.2022)

Текущий Xeon E5-2690 v3 можно заменить на **E5-2696 v4** за 2-4к ₽ (б/у):

| | E5-2690 v3 | E5-2696 v4 | Прирост |
|---|---|---|---|
| Ядра | 12 | **22** | **+83%** |
| L3 кеш | 30 MB | **55 MB** | **+83%** |
| Турбо | 3.5 ГГц | 3.6 ГГц | ~0% |
| Сокет | LGA 2011-3 | LGA 2011-3 | тот же |
| Архитектура | Haswell-EP (22нм) | **Broadwell-EP (14нм)** | холоднее |
| TDP | 135 Вт | **120-145 Вт** | требует обдув VRM |

**Совместимость с X99-TF: ✅ ПОДТВЕРЖДЕНО**
- Чипсет C612 — полная поддержка v3 и v4
- Официальный сайт Huananzhi: «supports E5-2686v4 / E5-2696v4»
- BIOS поддерживает Broadwell-EP (нужна версия ≥ 2020-05-25)

**Для LLM инференса:** прирост в токенах/с — скромный (+5-10%), потому что bottleneck в bandwidth DDR4 @ 2133, а не в ядрах. Для компиляции/многозадачности — прирост значительный (+40-80%).

**Стоит если:**
- Нашёл дешево (до 3-4к)
- Много компилируешь / параллельных билдов
- Хочешь забить последний апгрейд в платформу

**Не стоит если:**
- Покупаешь GPU для LLM (тогда CPU почти не участвует)
- LLM — единственная нагрузка

**⚠️ Важно перед обновлением BIOS:**
1. Проверь текущую версию: `msinfo32` → «Версия BIOS»
2. Если стоковый BIOS от Huananzhi — первый апдейт через USB + UEFI Shell
3. Если уже был обновлён — можно через AfuWin64 (есть в репозитории)
4. **Всегда делай бэкап текущего BIOS** программатором (NeoProgrammer) перед обновлением

## VRM зона и обдув

**VRM (Voltage Regulator Module)** — это цепи питания процессора на материнской плате. На X99-TF это **6-фазное питание** (6-phase power supply). VRM-зона — это место рядом с сокетом CPU, где расположены мосфеты и дроссели, преобразующие 12В от БП в напряжение CPU (~1.0-1.4В).

**Почему важен обдув:** при установке E5-2696 v4 (TDP 120-145Вт) VRM-зона нагревается. Без обдува мосфеты могут троттлить или выйти из строя.

**Какой вентилятор нужен:**
- Любой **80мм или 120мм вентилятор**, направленный на VRM-зону (рядом с сокетом)
- На X99-TF есть **2× SYS_FAN** (3-пин) — можно подключить вентилятор к одному из них
- Достаточно обычного корпусного вентилятора 80мм (~300-500₽)
- Важно: направить поток воздуха **на VRM-радиатор** (серебристый радиатор рядом с сокетом)

## Рекомендуемый порядок апгрейда

1. **Очистить NVMe (500 ГБ)** — бесплатно, сразу решит проблему с местом под модели
2. **Обновить BIOS** — до версии ≥ 2020-05-25 для поддержки v4
3. **CPU — E5-2696 v4** — добить платформу за копейки
4. **GPU — RTX 3060 12GB или P40 24GB** — x10 ускорение LLM против CPU
5. **Вентилятор на VRM** — 80мм, подключить к SYS_FAN
