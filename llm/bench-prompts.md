# Промты и эндпоинты бенчмарка LLM

Задача-конкурс красоты: один HTML-файл с анимированной солнечной системой.
Использовано для разделения моделей на слабые→сильные (главный критерий — объём/качество кода).

## Единый усиленный промт (NEW_PROMPT)
Использован **одинаковый** промт и для ОпенКодГо, и для Али, и для teamo (нон-китайцы).

```
Напиши один самодостаточный HTML-файл (HTML+CSS+JS, всё внутри, без внешних библиотек/шрифтов/CDN) —
визуально впечатляющую анимированную солнечную систему. Это конкурс красоты: код должен выглядеть как премиальный
веб-гаджет, а не учебная схема.

Обязательно:
1. Солнце в центре с эффектом свечения (радиальный градиент/glow, плавная пульсация плазмы).
2. 8 планет на своих круговых орбитах, у каждой своя орбитальная скорость (Меркурий — самая быстрая, Нептун — самая медленная).
3. Каждая планета с УНИКАЛЬНЫМ визуальным стилем: Юпитер — полосы, Сатурн — кольцо, Земля — голубая с материками и блеском,
Марс — красно-оранжевый, Венера — светло-жёлтая, Уран — голубовато-зелёный с вертикальным кольцом, Меркурий — серый, Нептун — глубоко-синий.
4. Красивый звёздный фон из множества мерцающих звёзд, элегантные тонкие орбиты, мягкие тени/свечение планет.
5. Плавная анимация (requestAnimationFrame), лёгкие следы орбит, аккуратная русская типографика подписей.
6. Тёмный космический UI, градиентный фон от угольно-чёрного к тёмно-синему.
7. Небольшой аккуратный заголовок вверху.

Сделай эстетически великолепно, удели внимание деталям и полировке. Верни ТОЛЬКО код.
```

**Параметры:** temperature 0.4, **без max_tokens** (по требованию Романа — `fin=length` давал обрезку кода), одно user-сообщение, OpenAI-compatible `/chat/completions`.

**Вариант для Anthropic-reasoning (fable/opus):** тот же промт + в конце добавлено
`ВАЖНО: НЕ рассуждай вслух и не трать токены на мысли — СРАЗУ напиши готовый HTML-код. Верни ТОЛЬКО код.`
— **не помогло** (те же 8192 токена в reasoning, 0 байт кода).

## Эндпоинты

### ОпенКодГо (open-code-go) — «все китайцы, кого нет на Али»
**ВАЖНО (исправлено 01.10): у моделей РАЗНЫЕ эндпоинты + нужен кастомный User-Agent.**

**Заголовки (обязательно, все три):**
- `Authorization: Bearer <OPENCODE_GO_API_KEY>`
- `x-opencode-session: <uuid>` (стабильный id диалога)
- **`User-Agent: my-coding-agent/1.0`** (кастомный UA агента; дефолтный UA питона/curl → **Cloudflare 403 code 1010**)

**Три семейства эндпоинтов по моделям** (docs: `/docs/ru/go` → «Эндпоинты»):
| Модель | Эндпоинт | Формат |
|---|---|---|
| GPT 6 Luna, GPT 5.6 Luna, Grok, Muse | `…/zen/go/v1/responses` | OpenAI Responses (`{"model","input"}`) |
| GLM, deepseek, mimo, kimi, longcat | `…/zen/go/v1/chat/completions` | OpenAI-compat |
| qwen3.8, minimax | `…/zen/go/v1/messages` | Anthropic-compat |

glm отдаёт контент в `content` (мысли отдельно — `reasoning_content`). База: `https://opencode.ai/zen/go/v1`.
**Результат:** после фикса (правильный эндпоинт + UA) — HTTP 200 на Luna (`/responses`) и GLM (`/chat/completions`). Раньше ломалось: Luna слалась на `/chat/completions` + дефолтный UA → 1010.

### Али token-plan (китайцы) — «не dashscope!»
- **Endpoint:** `https://token-plan.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1/chat/completions`
- **Заголовки:** `Authorization: Bearer <ALIBABA_TOKENPLAN_KEY>`
- **Провайдер в Hermes:** `qwen-tp`. **НЕ** dashscope (там 401).
- **Результат:** родные qwen (qwen3.6-flash/3.7-max/3.7-plus) работают отлично; **deepseek-v4-flash-0731 / deepseek-v4-pro / glm-5.2 — таймауты** на том же эндпоинте (не проблема пути — те же модели-запросы виснут апстрим).

### TeamoRouter (не-китайцы + топ-тир)
- **Endpoint:** `https://api.teamorouter.com/v1/chat/completions`
- **Заголовки:** `Authorization: Bearer <TEAMO_KEY>`
- grok-4.6, gpt-6-sol/6.1-sol/astra, gpt-6-luna, claude-haiku-4-5, kimi-k3 — проходят (kimi требует таймаут ≥900с). Антропик-reasoning (opus/fable) — пустой content.

## Тест простого промта (01.10) — гипотеза Романа подтверждена
Формулировка: **«сделай максимально красивую модель вселенной»** — одна фраза, без огорода требований, без max_tokens.

Сравнение для `gpt-6-astra` (teamo, одна и та же модель):

| Промт | Код | Холст (lit-пиксели 1920×1080) |
|---|---|---|
| усиленный, 7 пунктов | 11.2 KB, «Тихая геометрия космоса», 8 планет | 11 887 (редкий) |
| простой, 1 фраза | **14.6 KB**, спиральная галактика «Атлас бесконечности» + панель (пауза / время / ракурс) | **2 073 600 — весь холст** |

- **Вывод:** меньше ограничений → модель разворачивается сильнее и сама задаёт масштаб.
- Простой промт меняет и **предмет**: слово «вселенная» увело астру из солнечной системы в галактику. Для честного сравнения одной задачи нужен один и тот же сюжет, а не одна только «свобода».
- `gpt-6-luna` (ОпенКодГо, `/responses`) — 13.4 KB, «Наблюдаемая Вселенная»: Млечный Путь + космическая паутина + легенда, вращение/зум.
- `glm-5.3-flash` (ОпенКодГо) — **56 KB, но это ПРОЗА**: 0 `<canvas>`, 27 `function` плюс длинные описания («Сделаю живую, кинематографичную модель…»). **Метрика «объём байтов» врёт на словесных моделях** — смотреть на наличие `<canvas>`/живой рендер, не на размер.
- `deepseek-v4-flash` (ОпенКодГо) — завис таймаутом (та же картина и на Али).

## teamo в Hermes (регистрация 01.10)
Зарегистрирован, чтобы `gpt-6-luna` был доступен прямо из Гермеса: на провайдере `opencode-go` луна недоступна (Гермес шлёт туда `/chat/completions`, а луна отвечает только на `/responses`, которое Hermes не поддерживает — `HTTP 400 ModelProtocolUnsupported`).

- `providers.teamo` в `config.yaml`: `base_url https://api.teamorouter.com/v1`, `api_key ${TEAMO_KEY}`, `api_mode chat_completions`.
- `models.py`: `_PROVIDER_MODELS["teamo"]` + `ProviderEntry("teamo", …)` — иначе `teamo:model` не проходит `parse_model_input`.
- **Модели (6):** `gpt-6-luna`, `gpt-6.1-sol`, `grok-4.6`, `gpt-6-astra`, `gpt-6-sol`, `kimi-k3`.
- **Имена сверять с `GET /v1/models` (47 моделей), не гадать:** в teamo **нет** `gpt-6.1-luna` (есть `gpt-6-luna`/`gpt-5.6-luna`) и **нет** `grok-4.7` (есть только `grok-4.6`).
- Проверка маршрутизации: `hermes chat -q … --provider teamo -m gpt-6-luna` → `PONG73`, в логе `provider=custom base_url=https://api.teamorouter.com/v1`, `finish_reason=stop` (ответ одного провайдера не доказывает маршрут — сверять `agent.log`).
- **Гейтвей кэширует конфиг на старте** → после правки нужен рестарт гейтвея; CLI-сессии видят провайдер сразу.
