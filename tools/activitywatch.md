# ActivityWatch

Open-source автоматический трекер времени. Всё локально, никакого облака, полная приватность.

- **Репозиторий:** https://github.com/ActivityWatch/activitywatch
- **Сайт:** https://activitywatch.net/
- **Stars:** 18 631 (18.08.2026), forks 983, MPL-2.0
- **Язык:** Python
- **Создан:** 27.04.2016 (10 лет разработки)

## Что делает

Автоматически отслеживает, какие приложения/open windows занимают время. Веб-дашборд на `localhost:5600` с аналитикой по дням/неделям. Watchers (сборщики): активное окно, AFE-детектор, браузер-плагины. Расширяемо через REST API.
