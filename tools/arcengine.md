# ArcEngine (xaidan777)

Стартовый набор для **3D-игр в браузере**, сделанный «исключительно под LLM-кодинг».
Ниша: агент пишет логику игры, человек правит сцену и интерфейс в визуальном редакторе.

- **Репо:** https://github.com/xaidan777/ArcEngine
- **Лицензия:** MIT · **Язык:** ванильный JS (без сборки)
- **Движок:** Babylon.js 9.26 — лежит локально в `libs/`, ноль npm-зависимостей и CDN
- **Состояние на 13.10.2026:** 198 ⭐, 29 форков, 2 открытых issue; создан 15.09.2026,
  последний пуш 02.10.2026 — молодой, но живой
- **Требуется:** только Node.js (на VPS — v26.7.0, работает)

## Почему именно он

Искался движок для 3D-игр. Из проектов с именем «ArcEngine» под 3D подходят два, и этот —
единственный, заточенный под агентскую разработку:

| Проект | 3D | Подходит |
|---|---|---|
| **xaidan777/ArcEngine** | да (браузер, Babylon.js) | **да — под LLM-кодинг** |
| GloriousPtr/ArcGameEngine (AGE) | да (OpenGL, C++) | нет: хобби-проект, 0 релизов, автор сам пишет «bare-bones», забрасывается |
| arcprize/ARCEngine | нет (2D спрайты) | нет: движок игр-сред бенчмарка ARC-AGI-3 |
| jabza/ArcEngine | нет (2D ECS) | нет: мёртв с 2015 |
| ArcGIS Engine (Esri) | не игры | нет: GIS-компоненты, снят с поддержки 03.2026 |

Браузерная природа снимает требование к железу: WebGL-сцены идут и на слабой видеокарте
(на домашнем ПК Roman — GT 1030 2 ГБ).

## Что внутри

- `js/` — код игры, классические `<script>` и глобалы: `World3D`, `Terrain3D`, `Location3D`,
  `CameraControl`, `Model3D` (бинарный FBX), `Gltf3D` (GLB: скелет, клипы, PBR→toon),
  `Instances3D` (thin instances — много копий модели одним draw call), `Objects.js`,
  `UI.js`, `UILayout.js`, `Sound3D.js`, `Constants.js`, `Game.js`, `main.js`
- `_utils/editor/` — веб-редактор (EN/RU): камеры, toon вкл/выкл, вкладки Global Settings
  (пишет в `Constants.js`), Sound, Objects (импорт FBX/GLB, гизмо, анимация, теги),
  UI (раскладка драгом/ресайзом → `UILayout.js`), отмена Ctrl+Z, тур из 6 слайдов
- `claude/skills/` — 8 скиллов (`world3d`, `ui`, `sound`, `editor`, `build`,
  `render-conventions`, `verify`, `unity-port`), в формате `SKILL.md`, те же, что у Hermes.
  Инвариант набора: агент читает нужный скилл **до** правки кода
- `tools/` — `dev-server.mjs`, `check.mjs` (типы по JSDoc + тесты), `build.mjs`, `zip.mjs`,
  `asset-scan.mjs`, `make-character.mjs`, `make-sounds.mjs`, `export-unity.mjs`
- `unity/com.arcengine.runtime` — C#-двойник API и заготовка переноса прототипа в Unity
- `assets/` — текстуры земли (трава/песок/снег), модели `mill.fbx`, `Bush_3.fbx`,
  `character.glb` (клипы idle/run), звуки `farmer.mp3`, `mill.mp3`, `step.wav`
- `tests/` — 89 тестов на логику (Store, высоты террейна, сканер ассетов, запись редактора,
  звук, экспорт в Unity, связка скиллов); тестов рендера и ввода нет

## Ключевые инварианты (из `CLAUDE.md`)

1. **Ноль зависимостей** — ни npm, ни CDN, ни сборки; tsc берётся через `npx`, в проект не ставится
2. **Порядок скриптов значим**: `Constants.js` первым, `main.js` последним; новый скрипт —
   файл в `js/` + `<script>` в `index.html` + строка в `CODE_FILES` (`tools/asset-scan.mjs`)
3. **Все числа — в `Constants.js` литералами**: редактор патчит только `const ИМЯ = <число>;`
4. **3D — только представление**: логика игры хранит состояние сама и не спрашивает у Babylon
   высоты/пересечения для решений, которые должны совпадать на всех устройствах
5. Объекты мира — через `World3D.addObject(...)`; больше пары сотен копий — `addInstances(...)`
6. **Любой элемент UI — запись в `UILayout.js`** (через вкладку UI редактора); код игры не
   создаёт и не позиционирует HUD сам, только `UI.get('score').setText(...)`
7. Хранилище только через `Store` (`Constants.js`): в sandbox-iframe прямой `localStorage` бросает `SecurityError`
8. Скиллы и комментарии — **на английском** (кириллица в скилле = провал теста); русский
   остаётся только в строках (словарь `ru` редактора, вывод инструментов)
9. Всё, что нужно пользователю, — в путях **без точки**: веб-загрузка GitHub пропускает `.claude/`

## Чего в наборе нет

Физики и коллизий; готового игрока и противника (`Game.js` — только образец места для логики);
скелета и текстур у FBX (скелет/клипы/текстуры — только в GLB); нескольких сцен и уровней
(одна локация); сохранений прогресса; картинок и привязки UI к точке мира (виды элементов —
текст, панель, шкала, кнопка); преград, эха и доплера у звука.

## Запуск (нюанс для Linux)

`.bat` — Windows-only. На Linux (VPS) сервер поднимается напрямую:

```bash
cd /root/arcengine
node tools/dev-server.mjs --port=8080 --no-open
```

- слушает **127.0.0.1** (наружу не выставлен); при занятом порте сам берёт следующий (+20)
- все ответы с `no-store` — правку `.js` видно по F5; `python -m http.server` использовать нельзя
  (браузер закэширует старый скрипт)
- перед стартом — проверка ассетов: «ok все 8 ассетов на месте»
- `node tools/check.mjs` — типы + тесты (89 тестов, все зелёные)

## Как с ним работать агенту

1. Открыть папку в кодинг-агенте (Claude Code или любом другом — формат скиллов общий)
2. Прочитать `CLAUDE.md` и нужный скилл из `claude/skills/<имя>/SKILL.md` до правки
3. Логику писать в `js/Game.js` (или новые файлы с регистрацией в `index.html` и `CODE_FILES`)
4. После правки — `node tools/check.mjs`; после правки геометрии/света/шейдеров — ещё
   `Debug3D.lint()` в игре

Игра доступна по адресу **https://rem2222.top/arcengine/** (nginx → `127.0.0.1:8082`).

- в `sites-enabled/hermes` добавлен `location ^~ /arcengine/` с `proxy_pass http://127.0.0.1:8082/;`
  и `location = /arcengine { return 301 /arcengine/; }`; бэкап конфига —
  `/root/backups/nginx-hermes.before-arcengine.20261013-200037`
- **`^~` обязателен**: regex-локейшн Multica уводит односегментные пути, а префиксный локейшн
  имеет приоритет над regex (тот же камень, что с `/mascots/`)
- **без Authelia** — игра только читает файлы китa, секретов там нет; dev-server защищён от выхода
  за пределы корня
- все пути внутри китa относительные (`libs/…`, `assets/…`) — поэтому подпуть работает без правок
- проверено через публичный HTTPS: index 200, `babylon.js` 200 (8.3 МБ), `character.glb` 200,
  редирект с `/arcengine` → 301; в браузере Babylon.js v9.26.0 WebGL2 и «локация запущена»

**Редактор сцены (`8095`) наружу НЕ выставлен** — он умеет записывать `Constants.js`, `Objects.js`
и `UILayout.js`, поэтому без авторизации его публиковать нельзя. Если понадобится — только через
Authelia-локейшн.
