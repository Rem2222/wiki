# Unity AI Agents Plugin

Официальный плагин Unity для ИИ-агентов.

## Что это

Unity выпустила официальный MCP-плагин, дающий AI-агентам доступ к 29 навыкам движка: интерфейс, графика, звук, физика, сцены, мультиплеер, локализация и др.

## Поддерживаемые агенты

- Claude Code (изначально)
- Codex
- Grok

## Навыки (29 шт.)

UI, Rendering, Audio, Physics, Scenes, Multiplayer, Localization и другие подсистемы Unity.

## Демо

Codex + Unity MCP + Blender MCP: агент создаёт модели → риг → анимации в Blender → переносит в Unity → пишет и запускает автотесты.

## Зачем для нашей игры

- MCP-плагин = стандартный интерфейс для AI-разработки в Unity
- Команда Unity сама пишет навыки — качество выше community-плагинов
- Работает с Codex и Grok — можно использовать наши текущие подписки
