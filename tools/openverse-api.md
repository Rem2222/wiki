# Openverse API — бесплатные звуки и картинки для проектов

REST API библиотеки Openverse (WordPress Foundation): ~5,2 млн аудиофайлов (из них ~590 тыс. звуковых эффектов и ~640 тыс. музыкальных треков) плюс изображения. Ключ и регистрация **не нужны**.

## Проверено на VPS (18.10.2026)

- Анонимный запрос работает: HTTP 200 без ключа
- Лимиты (из заголовков ответа): `x-ratelimit-limit-anon_burst: 20/min`, `x-ratelimit-limit-anon_sustained: 200/day` — то есть **20 запросов в минуту и 200 в сутки**
- Проверенный запрос:
  ```
  curl "https://api.openverse.org/v1/audio/?q=whoosh&license=cc0,by,pdm&source=freesound,jamendo&page_size=3"
  ```
- Фильтры работают: выдача содержит только указанные источники и лицензии (по запросу «whoosh» — 240 результатов, всё freesound + CC0)
- Файл скачивается: прямая ссылка отдала валидный MP3 (128 kbps, stereo)

## Структура ответа

В ответе `result_count` и `results[]`, у каждого элемента:

- `title`, `source` (freesound / jamendo), `license` + `license_version`
- `url` — **прямая ссылка на mp3-превью** (cdn.freesound.org), именно её и надо скачивать
- `attribution` — готовая строка для `credits.txt`, копировать дословно

## Подводные камни

- Поле `files` в ответе **пустое** — качать по `url`, а не из `files`
- Лимит 200/сутки → на каждый тип звука делать **один** поиск и выбирать из выдачи
- Для коммерческих проектов — добавлять `license_type=commercial`
- Изображения — тот же API: `/v1/images/`

## Промпт-инструкция для агента (подбор SFX под кадры)

> Если в проекте нет подходящего звукового эффекта, выполни поиск через Openverse — https://api.openverse.org
> Используй только результаты с `license=cc0,by,pdm` и `source=freesound,jamendo`. Для каждого типа звука выполняй поиск только один раз (для анонимных пользователей действует ограничение в 200 поисковых запросов в сутки).
> Подбери наиболее подходящий эффект с учётом действия в каждом кадре, скачай выбранный файл по его URL с помощью `curl` в папку `sfx/` и скопируй поле `attribution` каждого результата в `credits.txt` без изменений.

## Где применять

- Видео (HyperFrames / Remotion): звуки переходов, щелчки, фоновый шум, музыка
- Игры: ассеты звука и изображений с CC0-лицензией
