1. desk-emoji (uncle-mark/desk-emoji)

Что этонастольный робот-эмодзи: круглый экран вместо лица, две сервы (пан/наклон), микрофон, динамик, датчик, LED-подсветка. Говорит, показывает эмоции, поворачивает голову.
Репозиторий598 ⭐, 102 форка, ~26 МБ, GPL-3.0, последний пуш 05.11.2026
Цена набора$150 на краудфандинге PledgeBox / Rally (плюс доставка). Автор — Mark Yang (ewen.ltd), продаёт и на Taobao, ведёт Bilibili
ЖелезоESP32-S3 (в репо есть прошивки и под ESP32, Arduino UNO R3, UNO R4 Minima) + круглый экран + 2 сервы + I2S-микрофон + динамик
3D-моделинетSTL/STEP/3MF в репозитории отсутствуют — корпус только покупной

Как устроена прошивка (28 файлов Arduino C++)

кнопка / жест→микрофон (I2S)→ASR по WebSocket→ LLM: api.openai.com напрямую→движения (async-последовательность) + TTS
  • net.cpp — робот поднимает Wi-Fi-точку доступа с веб-страницей настройки: сеть и ключ вводятся в браузере телефона, без перепрошивки. Плюс UDP и OTA
  • asr.cpp / tts.cpp — стриминговый звук по WebSocket, китайский сервис с appid (свой ключ в настройках)
  • llm.cpp — вызов OpenAI-совместимого чата с ключом из настроек; модель возвращает не только текст, но и эмоцию + действие из фиксированного набора
  • emoji.cpp, animation.cpp, head/act — анимации глаз и плавные последовательности движений серв
  • в простое «живёт»: случайные микродвижения каждые 6–10 секунд, LED показывает состояние (слушает / думает)

Где здесь мозг

Мозг внутри робота. ESP32-S3 сам ходит в ASR, LLM и TTS по WebSocket и сам решает, какое движение выполнить. ПК-клиент (Python, customtkinter, версии 3.9–3.11) нужен только для настройки, теста и заливки прошивки — в репозитории есть и отдельная ветка pc_client_gemini_v3.1 под Gemini realtime.

Это принципиально другая схема, чем у «куклы на поводке» (робот = исполнитель команд с ПК): здесь робот живёт сам, а компьютер только обслуживает.

Чего в нём нет

  • MCP и вызова инструментов — LLM умеет только текст + эмоция/движение, внешние сервисы звать нечем
  • камеры, распознавания лица, памяти между разговорами, локальной автономности без Wi-Fi
  • 3D-моделей корпуса (см. выше) и схем платы в открытом виде
Лицензия: GPL-3.0, но в README автор отдельно пишет «коммерческое использование запрещено». Формулировка противоречит GPL — трактовать в свою пользу не стоит. Для нас: код не копировать, брать только идеи.

2. Платформа, на которой сидят почти все — xiaozhi

Раскладка простая: прошивка = клиент, сервер = мозг. Производители плат (M5Stack, наборы для уток, десятки ESP32-плат) не пишут своё — берут прошивку xiaozhi и продают железо. Меняешь сервер — меняешь «личность» робота, не трогая железо.

Что у сервера внутри (по каталогу документации)

  • MCP-точка доступа — docs/mcp-endpoint-enable.md, mcp-endpoint-integration.md, mcp-vision-integration.md, mcp-get-device-info.md: устройство зовёт внешние инструменты через MCP
  • идентификация по голосу (voiceprint), база знаний через RAGFlow, интеграция Home Assistant
  • плагины: веб-поиск, погода, новости, цифровой человек, клонирование голоса, OTA-обновление прошивок с сервера
  • два режима установки: упрощённый (Docker без БД, конфиг в файлах, один агент) и полный (MySQL + Redis + веб-консоль, много пользователей и агентов)
  • в README прямо сказано: проект учебный, не проходил аудит безопасности, в прод не ставить
Почему это важно для нас: у сервера есть MCP-endpoint. Значит тело можно связать с нашим SmithsChat MCP (127.0.0.1:8790) — робот будет не только болтать, но и звать инструменты. Официальных требований по железу в доках нет: самое тяжёлое — локальный FunASR, с облачными API хватает скромной машины.

Вывод
  • Дешёвый и правильный путь: StackChan $99 (или голая ESP32-S3 + прошивка xiaozhi) + свой xiaozhi-esp32-server, в него MCP-endpoint на SmithsChat. Тело начнёт звать инструменты, а не только болтать.
  • desk-emoji — не как код (GPL + запрет коммерческого), а как учебник: настройка Wi-Fi через веб-страницу самого устройства, асинхронные последовательности движений, эмоции на экране, режим «жизни» в простое. Это ровно те приёмы, которых не хватает своим поделкам.
  • Microduck и Reachy — про моторику и дорого; для «тела агента» не нужны.
  • Покупать ничего не будем без слова. Если решим — первым берём StackChan: единственная цена, подтверждённая живой страницей ($99 у M5Stack; DigiKey и Pi Hut отдают 429/403 на наш IP, AliExpress-поиск — 302).
