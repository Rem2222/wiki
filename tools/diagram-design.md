# diagram-design

Библиотека 27 типов редакционных диаграмм (block, flow, timeline, matrix, sankey, chord и т.д.) в самодостаточном HTML/SVG. Предназначена для AI-агентов (Claude Code) — LLM генерирует готовый HTML-файл без зависимостей.

- **Репозиторий:** https://github.com/cathrynlavery/diagram-design
- **Stars:** 21 204 (18.08.2026), forks 1 309, MIT
- **Язык:** HTML (чистый SVG, без JS-библиотек)
- **Создан:** 16.04.2026

## Что внутри

27 шаблонов: block diagram, flowchart, timeline, matrix, sankey, chord, treemap, parallel coordinates, radar chart, funnel, pyramid, network graph, geographic map и другие. Каждый — HTML-файл с inline SVG, который можно открыть в браузере или встроить в документ.

## Зачем

Замена Mermaid: «No shadows, no Mermaid-slop» — редакционный минималистичный стиль. Удобно для:
- Документации архитектуры
- Презентаций (встраивается в HTML)
- Статей и отчётов
