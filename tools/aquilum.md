# Aquilum — аналог Obsidian на Rust

**Репо:** github.com/Freaction/Aquilum · **без лицензии** · только Windows
**Источник:** статья на Хабре habr.com/ru/articles/1090122/ (03.10.2026, 9 мин, 20K)

Локальный (local-first) заметочник на Markdown. Автор — дизайнер `dima_yiu`,
делал из-за раздражения от памяти Obsidian и разнобоя в визуале плагинов.

## Заявленные цифры

| | Aquilum | Obsidian (по автору) |
|---|---|---|
| ОЗУ | **27 МБ** | «гигабайт с лишним» |
| Установщик | 11 МБ | — |
| Поиск | 1–2 мс на 1000 заметок | — |

Причина расходов честная: **Tauri 2 вместо Electron** — Obsidian тянет свой
браузерный движок, Aquilum нет. Это не маркетинг, а прямое следствие архитектуры.

**Стек:** Rust + Tauri 2 · React + TypeScript · CodeMirror 6 (тот же движок, что
в Obsidian) · Yjs (локальная модель документа) · SQLite (состояние) ·
BM25F (полнотекстовый поиск) · Markdown как формат хранения.

## Функционал

- обратные ссылки и **граф знаний** с тепловой картой «что давно не обновлялось»
  (фильтр по дате создания) — автор хотел рабочий инструмент, а не декорацию
- **Dataview-подобные запросы** — синтаксис переработан, переписан на Rust,
  мгновенный отклик. Примеры в статье: последние заметки, стата по периодам,
  невыполненные задачи
- **MCP-сервер**: Claude Code, Codex CLI, Gemini Antigravity — агенты ищут через
  BM25F, смотрят связи, редактируют заметки в нескольких базах одновременно
- версионирование внутри заметки (откат правок, в том числе правок ИИ-агента)
- корзина (в Obsidian удалённая заметка пропадала безвозвратно)
- таблицы с merge/split ячеек и форматированием внутри
- читалка книг: цитаты уходят в заметку со ссылкой на фрагмент,
  прогресс чтения — в frontmatter (счётчик привязан к размеру файла)
- шаблоны, frontmatter, темы (светлая/тёмная), лайв-превью, медиа с crop
- несколько баз знаний с переключением, одна из команд MCP — переключение баз
- корзина, hotkeys, подсветка совпадений в поиске

## 🔴 Исходники не открыты — главное

Проверено по API 05.10.2026:

- в репо только `README.md`, `README.ru.md`, логотип и 12 скриншотов.
  **Ни одного `.rs`, ни одного исходного файла**
- `license: null`, файла LICENSE нет
- **`Source code (zip)` в релизе содержит те же скриншоты**, не код.
  Комментатор `mikamiel` под issue #1: «в архив с названием Source code
  положить пачку скриншотов. Браво»
- **все 3 issue — про отсутствие исходников** («открой код», «нужен Linux»),
  ответов от автора нет
- релиз `v0.1.8` (04.10.2026) в коммите помечен
  `Co-Authored-By: Claude Opus 5 (1M context)`

При этом статья заявляет: «хотелось открытости и портативности, чтобы все
данные всегда были у меня». Про **данные** это правда — чистый Markdown на диске,
без облака и формата-ловушки. Про **исходники** — уже нет.

## Решение: НЕ устанавливать

Причина — не «закрытый код вообще», а **конкретная комбинация**:

1. бинарник без лицензии и без единой возможности проверить, что внутри;
2. приложение получает доступ **ко всей базе заметок** — это чувствительные
   персональные данные;
3. подмена `Source code (zip)` скриншотами — это не «проект не успели
   открыть», а осознанное оформление;
4. автор молчит на все три issue;
5. 64 ГБ RAM на XE2690 — драйвер «27 МБ ОЗУ» для Романа не работает вообще.

Если откроют исходники и добавят лицензию — пересмотреть. Проверять по:
`curl -s https://api.github.com/repos/Freaction/Aquilum` → поле `license`
должно перестать быть `null`, и в дереве `main` должны появиться `.rs`.

## Что интересного на самом деле

- **MCP-команды без костылей** — переключение баз знаний и поиск по BM25F
  из коробки, у нас Obsidian-MCP идёт через плагин
- **граф с тепловой картой по дате обновления** — «что заброшено» как
  рабочий критерий, а не красивая картинка
- **версионирование, переживающее правки ИИ-агента** — релевантно для Декса:
  откат потери агентом важного текста
