# BrowserSkill (Tencent)

Опенсорс утилита от Tencent для подключения ИИ-агентов к реальному браузеру пользователя (с аккаунтами и куками).

## Суть

Обычно агент получает чистый изолированный браузер без авторизаций. BrowserSkill даёт агенту доступ к **вашему настоящему браузеру** — с логинами, куками, сессиями.

## Как работает

- Агент действует в **отдельном видимом окне**
- Если нужна вкладка пользователя — **запрашивает разрешение**, временно забирает, возвращает после задачи
- Капчи и подтверждения → передаются пользователю, потом работа продолжается
- **Не MCP-сервер** — локальная CLI-утилита + расширение для браузера
- Работает с любым агентом, умеющим выполнять команды в терминале

## Поддержка

- **ОС:** Windows, macOS, Linux
- **Лицензия:** MIT
- **Агенты:** Codex, Claude Code, Cursor, Hermes и др.

## Зачем

- Агент может работать на сайтах, где вы авторизованы ( banking, корп. порталы, CRM )
- Не нужно вводить логины/пароли в агент — берёт из браузера
- Безопасно: пользователь контролирует каждую вкладку
