# RDP Monster

VPS-провайдер без KYC с оплатой криптой. Рекомендован Rem2222 для анонимного хостинга.

## Преимущества

- **Без KYC** — не нужно подтверждать личность
- **Оплата криптой** — включая анонимные монеты; картой тоже можно
- **КВН приветствуется** — можно запускать что угодно
- **Безлимитный трафик** — важно для КВН
- **Приятные цены**
