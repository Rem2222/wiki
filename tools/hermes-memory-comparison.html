Легенда точек: хорошо · средне/частично · слабо.
Стабильность = устойчивость к падению/утечкам без ручного восстановления (Node-движок слабее Go/SQLite-бинарника).
Авто-retrieve = сам ли ищет память перед turn («посмотри в памяти» без напоминаний).
Durability влияет на стаб.: локальный диск цел при падении процесса, облако — нет сети = нет памяти.
