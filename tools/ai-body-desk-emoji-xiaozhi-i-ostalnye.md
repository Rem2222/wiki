# Тело для ИИ: три вопроса и три ответа

Полная версия с таблицами — `https://rem2222.top/ai-body.html` (за Authelia), исходник `tools/ai-body-desk-emoji-xiaozhi-i-ostalnye.html`.

## 1. desk-emoji (uncle-mark) — что это на самом деле

- 598 ⭐, 102 форка, GPL-3.0, последний пуш 05.11.2026; набор **$150** на краудфандинге PledgeBox/Rally, автор Mark Yang (ewen.ltd), продажи на Taobao.
- Железо: **ESP32-S3** (в репо есть и ESP32, UNO R3, UNO R4 Minima), круглый экран-лицо, 2 сервы (пан/наклон), I2S-микрофон, динамик, датчик, LED.
- **3D-моделей корпуса в репозитории нет** — STL/STEP/3MF отсутствуют, корпус только покупной.
- Прошивка — Arduino C++, 28 файлов:
  - `net.cpp` — устройство поднимает Wi-Fi-точку с веб-страницей настройки (сеть/ключ вводятся с телефона), UDP + OTA;
  - `asr.cpp` / `tts.cpp` — стриминг по WebSocket, китайский сервис с `appid`;
  - `llm.cpp` — прямой вызов `api.openai.com`; модель возвращает текст + **эмоцию и действие** из фиксированного набора;
  - `emoji.cpp` / `animation.cpp` / `head` / `act` — анимации и плавные последовательности серв;
  - в простое «живёт»: случайные микродвижения каждые 6–10 с, LED показывает состояние.
- **Мозг внутри робота**, ПК-клиент (Python, customtkinter, 3.9–3.11) — только настройка/тест/прошивка; есть отдельная ветка `pc_client_gemini_v3.1` под Gemini realtime.
- Чего нет: MCP и вызова инструментов, камеры, памяти между разговорами, автономности без Wi-Fi.
- Лицензия: GPL-3.0, но README отдельно запрещает коммерческое использование — противоречие; **код не копировать, брать идеи**.

## 2. Платформа, на которой сидят почти все — xiaozhi

Схема: **прошивка = клиент, сервер = мозг**. Вендоры плат не пишут своё, а берут прошивку и продают железо; меняешь сервер — меняешь личность робота.

- `78/xiaozhi-esp32` — 33 227 ⭐, MIT: 171 вариант платы, офлайн-вейкворд, AEC, Opus-поток, экран/эмоции, камера, **MCP и на устройстве, и на облаке**.
- `xinnan-tech/xiaozhi-esp32-server` — 11 292 ⭐, MIT: Python + Java + Vue, `docker-setup.sh`, транспорты MQTT+UDP и WebSocket по протоколу Xiaozhi Communication Protocol.
- Внутри сервера: MCP-точка доступа (`docs/mcp-endpoint-*.md`), voiceprint, RAGFlow, Home Assistant, плагины (веб-поиск, погода, новости, цифровой человек, клонирование голоса), OTA прошивок; два режима — упрощённый (Docker без БД) и полный (MySQL + Redis + веб-консоль).
- README прямо предупреждает: аудита безопасности не было, в прод не ставить.
- **Для нас главное:** MCP-endpoint сервера позволяет подключить SmithsChat MCP (`127.0.0.1:8790`) — тело будет звать инструменты, а не только разговаривать.

## 3. Саммари по остальным

- **StackChan** (M5Stack) — $99, с пультом $125, Apache-2.0, `stack-chan` 1 874 ⭐: ESP32-S3, 2" тач, камера, 2 сервы, NFC, батарея; форк `dotty-stackchan` (127 ⭐ MIT) — полностью домашний стек (ASR/TTS локально, LLM любой). **Лучший вход.**
- **Flashduck** — MIT, 174–182 ⭐, утка на ESP32-S3, 6 серв, корпус печатается; голос через xiaozhi.me или свой сервер; вторая прошивка **DuckClaw** — агент внутри, рулит шестью суставами через MCP.
- **Microduck** (Pollen) — $399, Apache-2.0, 13 798 ⭐ + `microduck_rl` 2 897 ⭐: 25 см, 800 г, 15 серв, RK3566; «ИИ» = обучение движению (MuJoCo + PPO → ONNX), диалога и MCP нет. Не под задачу.
- **Reachy Mini Lite** — $399 DIY-набор (~2.5 ч сборки), Hoverboard $149 отдельно, SDK Python/JS, 1 660 ⭐. Честно, но дорого.
- **PiDog** (SunFounder) — $149.99; под него `rockywuest/pidog-embodiment` (MIT) с формулировкой «дай ИИ физическое тело».
- **OpenCat** (Petoi) — 5 563 ⭐ MIT, четвероногий конструктор. **LeRobot** — 28 879 ⭐, манипуляторы.

## Вывод

1. Дешёвый и правильный путь — **StackChan $99 или голая ESP32-S3 + xiaozhi**, сервер свой (`xiaozhi-esp32-server`), в него MCP на SmithsChat.
2. **desk-emoji** — не код (GPL + запрет коммерции), а учебник: настройка через веб-страницу самого устройства, асинхронные движения, эмоции, режим «жизни» в простое.
3. Microduck и Reachy про моторику и дорого — для «тела агента» не нужны.
4. Ничего не покупаем без слова Романа. Цена подтверждена живьём только у StackChan ($99); DigiKey/Pi Hut/SunFounder отдают 429/403 с нашего IP, поиск AliExpress — 302.
