# ИИкона (КИИ) — AI-коннектор для 1С

## Что это

Расширение для **1С:Предприятие 8.3** (8.3.24+), интегрирующее LLM в конфигурации. С v1.3.0 стало платформой: коннектор + агентская петля + RAG + MCP-сервер + мониторинг ошибок + генератор диаграмм. Ставится как расширение — основную конфигурацию не изменяет.

## Ключевые возможности

**Коннектор (ядро):**
- 5 форматов провайдеров: OpenAI-compatible, Anthropic, Google Gemini, YandexGPT, GigaChat
- 25+ предустановленных моделей (GPT-4/5.x, Claude, Gemini, DeepSeek, Qwen, Mistral, Ollama, LM Studio)
- Синхронные/асинхронные запросы, кеш ответов с TTL, логирование (токены, время, ошибки)
- Мультимодальность: изображения + документы + генерация изображений
- Повторы с экспоненциальным backoff (429/5xx)

**Агентская петля (function calling):**
- Модель вызывает инструменты 1С и продолжает рассуждение — во всех 5 форматах провайдеров
- Лимиты раундов/вызовов, дедупликация, аудит каждого вызова

**RAG — база знаний:**
- Категории знаний, авто-нарезка на фрагменты, эмбеддинги с версионированием
- Два бэкенда: встроенный (чистый 1С) и **Qdrant** (~1900× быстрее: 9 мс vs 17 с на 5000 фрагментов)
- Egress-политики: конфиденциальные фрагменты не покидают базу

**MCP-сервер:**
- HTTP-сервис (JSON-RPC 2.0) для внешних ИИ-агентов (Claude Desktop, Cursor)
- Инструменты: метаданные конфигурации, read-only запросы, диаграммы
- Basic Auth, rate limiting, whitelist, аудит

**Мониторинг ошибок:**
- Сбор из журнала регистрации → нормализация → дедупликация → ИИ-анализ
- Уведомления в Telegram с антиспамом, статистика, HTML-дашборд

**Аудитор кода:**
- По ошибке находит место в исходниках → собирает контекст через rlm-tools-bsl → диагноз через модель

**Генератор диаграмм:**
- Текст → mermaid / plantuml / graphviz / bpmn (mermaid локально, остальные через kroki)

## Технологический стек

- **Платформа:** 1С:Предприятие 8.3.24+ (тестировалась на 8.3.27)
- **Язык:** BSL (~23 000 строк, 34 общих модуля)
- **Тестирование:** 398 модульных тестов YAxUnit
- **Качество:** SonarQube — 0 замечаний, рейтинг A/A, техдолг 0
- **Файл:** .cfe (956 KB)
- **Требования:** БСП 3.1.10+

## Установка

1. Скачать .cfe из Releases
2. Подключить расширение (Администрирование → Расширения конфигурации)
3. Обновить БД → «Заполнить модели» (25+ предустановок)
4. Указать API-ключи (защищённое хранилище 1С)
5. Создать «Эксперта ИИ»: модель + системный промпт

## Быстрый старт

```bsl
Модель = Справочники.КИИ_МоделиИИ.НайтиПоНаименованию("gpt-4");
Ответ = КИИ_КоннекторИИ.ЗапросКМодели(Модель, "Привет! Как дела?");
ОбщегоНазначения.СообщитьПользователю(Ответ.ТекстОтвета);
```
