# v0 от Vercel — агент, который собирает и деплоит full-stack приложения

## Что это

**v0** (v0.app) — продукт Vercel, самоописание на странице: «Build Full-Stack Web Apps with AI». По официальным docs: «Ship features, refine designs, update copy, and create live prototypes, all with a prompt. Deploy to production immediately, or open a pull request for review».

Ключевое отличие от «генератора кода по описанию»: v0 заявляет себя как **агент**. Он ищет в вебе, открывает и использует приложения, которые сам собрал (browser use — со скриншотами того, что видит), сам диагностирует и правит ошибки, выполняет команды в терминале, дёргает внешние инструменты. Всё это в изолированной песочнице, а степень автономии настраивается.

Раньше это был генератор React-компонентов для лендингов; сейчас это среда «промпт → работающее full-stack приложение → деплой».

## Как устроена работа

- **Песочница** — Vercel Sandbox: лёгкая виртуальная машина с полноценным Node.js, поднимается за секунды. Внутри три поверхности: Preview (приложение на dev-сервере), Console (логи и терминал), Code viewer (файлы, правка, комментарии как контекст для следующего промпта)
- **Пакетные менеджеры** — pnpm, npm, yarn, bun доступны сразу, ставить зависимости можно любые
- **Переменные окружения** берутся из подключённого Vercel-проекта и доступны и приложению, и инструментам агента
- **Изоляция** по трём осям: на чат (своя VM, файлы и процессы не перетекают), на пользователя или команду, на песочницу в целом
- **Fix with v0** — на странице деплоя кнопка отправляет логи ошибки агенту, он диагностирует и правит. На платных планах до 10 бесплатных исправлений в день, но только для кода, который не правили руками: если правил — спишутся кредиты

Важная деталь для понимания: раньше превью было браузерным и не умело серверный код, API-роуты и реальные подключения к базе. С переходом на VM-песочницу превью ведёт себя как развёрнутое приложение.

## Стек

По умолчанию Next.js. По ссылкам из самих docs поддерживаются также Nuxt, SvelteKit, Nitro, TanStack Start и FastAPI — всё в экосистеме Vercel. Код синкается с GitHub, то есть забрать его и хостить в другом месте можно, но родной путь — деплой на Vercel в один клик.

## MCP: как есть на самом деле

Два способа подключения:

1. **Свой MCP-сервер** — через меню «+» в поле промпта. Поддерживаются четыре вида аутентификации: без авторизации, кастомные заголовки, Bearer-токен, OAuth 2.0. Есть пресеты: Context7, Sentry, PostHog, Linear, Notion, Datadog, Slack, Vercel, Zapier, Contentful, Sanity, Glean, Granola, Hex, Mobbin, Nitrosend
2. **MCP из интеграций Vercel Marketplace** — Neon, Supabase, Upstash, Stripe и подобные, без ручной настройки

**Ограничение, которое легко упустить:** MCP-инструменты доступны **агенту v0 во время генерации**, а не тому коду, который он создаёт. В docs прямо: «the generation v0 creates cannot use the MCP tools directly». То есть подключить MCP, чтобы приложение само дёргало инструменты, не получится — это инструмент ассистента, а не рантайма.

Плюс предупреждение самих docs: включение remote MCP может увеличить стоимость сообщения и дать агенту доступ к чтению или изменению внешних данных; перед включением советуют настроить Agent Permissions.

## Цены (страница pricing, 08.11.2026)

- **Free** — $0, разово $5 кредитов новому пользователю, деплой на Vercel, Design Mode, синк с GitHub, **лимит 7 сообщений в день**
- **Plus** — **$30** в месяц за пользователя (на странице рядом стоит зачёркнутое $90, то есть это акционная цена). Доступ ко всем моделям, $30 включённых кредитов в месяц на пользователя, $2 бесплатных дневных кредитов при входе, докупка кредитов, общий биллинг на vercel.com, шаринг чатов
- **Business** — $100 в месяц за пользователя: всё из Plus плюс **отказ от обучения на данных включён по умолчанию**
- **Enterprise** — по договору: данные никогда не используются для обучения, SAML SSO, роли, приоритет без очередей, SLA

Ставки моделей за миллион токенов (вход / запись кэша / чтение кэша / выход):

- **v0 Mini** — $0.20 / $0.25 / $0.02 / $1.20
- **v0 Pro** — $2 / $2.50 / $0.20 / $10
- **v0 Max** — $5 / … (на странице ставки обрезаны, дальше надо смотреть на самой странице)

## Что это значит практически

**Сильные стороны.** Быстрый путь от идеи до работающего прототипа с настоящим сервером, а не картинкой. Агент сам проверяет результат в браузере и чинит ошибки — это заметно больше, чем «сгенерируй компонент». MCP-подключения и интеграции с базами дают контекст. Код уходит в GitHub, то есть не запирается в редакторе.

**Слабые стороны и риски.**

- **Данные.** Отказ от обучения по умолчанию только с Business. На Free и Plus данные могут использоваться, пока не отключишь сам. Для рабочего кода заказчиков (и тем более для 1С-выгрузок) это существенно
- **Вендор.** Родной деплой — Vercel, стек — их фреймворки. Забрать код через GitHub можно, но инфраструктурные привязки (KV, интеграции, env) придётся переделывать
- **Цена за сообщения.** Free — 7 сообщений в день, это очень мало для реальной работы. Plus — $30 с кредитами, которые при сложных итерациях уходят быстро; на странице есть отдельный FAQ «Why do messages use so many input tokens?»
- **MCP только для ассистента**, не для рантайма приложения — легко купить не то, что ожидал

**Кому подходит.** Прототип интерфейса к обсуждению, дашборд, лендинг, PRD-макет, «показать заказчику как будет». Не подходит как замена своей разработке: у нас на VPS уже есть и HTML-отчёты, и дашборды, и свои морды, которые не зависят от подписки и не отдают данные наружу.
